# humanizer-zh（Obsidian 知识库整理版）

面向面试导向 AI Agent 知识库的“去 AI 味”Agent Skill。

用途：把与设计 Agent 的讨论记录、语音转写、代码分析结论、网页资料和旧笔记整理或改写成 Obsidian 知识笔记，并按用户给设计 Agent 定下的文风规则消除 AI 味——空泛升华、模板连接词、机械三段式、“本质上/核心是”类强调表达、碎片化条目、术语包装、重复总结与聊天残留。改写时锁定事实、术语、数字、代码、链接、限定条件和事实层级，不用“编细节”的方式假装真人，也不把“共同设计的方案”写成“已经实现”。同时保证概念讲得懂：重要标识符、缩写和机制首次出现时给出中文解释（是什么、为什么存在、起什么作用），正文以中文叙述为主、克制英文穿插，一个小节把一个概念讲完再进入下一个。定义型代码块（数据类、SQL、配置、载荷）逐字段加中文注释；边界与选型问题用「Q：/A：」问答对统一收束在笔记末尾；小节标题引入术语时，第一句先落地其含义。

## 与上游版本的关系

本项目基于 [blader/humanizer](https://github.com/blader/humanizer) v2.9.1 的核心原则重新设计：

- 保留事实，不按原文句式机械改写
- 不新增来源中不存在的信息
- 支持使用本人旧文校准声线
- 避免把单个词语或标点误判成 AI 写作

中文增强版 `humanizer-zh` 加入了 36 组中文模式；本仓库是它的进一步改写，面向 Obsidian 知识库整理场景，将平台模板腔（公众号、小红书、短视频、商业汇报）替换为知识笔记特有的模式（材料顺序即结构、平均用力、自包含重复、伪造概念关联、事实层级拉平、章节越界等），并内置 Obsidian 结构规范（frontmatter、内部链接、概念唯一归属、章节边界、图表克制）。

这不是 AI 检测器，也不承诺绕过任何检测系统。它只负责改善表达。

## 安装

这是一个以 `SKILL.md` 为入口的通用 Agent Skill，不依赖脚本、API、MCP 或环境变量。将整个 `humanizer-zh` 目录放入所用 Agent 的 Skills 目录即可，安装后应保持 `SKILL.md` 位于目录根部。

## 使用方法

整理成稿（核心场景）：

```text
请使用 humanizer-zh，把下面这段讨论记录整理成知识笔记。
保留所有术语、数字和结论，按“当前最终设计 + 待确认”的结构重组，不要新增信息。

【粘贴讨论记录】
```

去 AI 味改写：

```text
请使用 humanizer-zh 修改下面这篇笔记。
保留事实和事实层级，按工程文档风格改得直接一点，不要新增信息。

【粘贴原文】
```

审校并说明：

```text
请使用 humanizer-zh 的审校模式。
先指出最明显的 AI 模板腔，再给我可以直接落盘的终稿。

【粘贴原文】
```

## 适用内容

- 与设计 Agent 的讨论记录、语音转写整理
- 代码 / GitHub 仓库分析结论整理
- 已有知识笔记的去 AI 味改写与审校
- 旧笔记的合并、拆分与去重
- 网页资料、教程体的中性化改写
- 其他中文文本（公众号、邮件等）仍适用核心规则
