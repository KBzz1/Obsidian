# 长期记忆语义模型

## 三种记忆语义

长期记忆从认知分类上落地为两类：情节记忆（Episodic Memory）和语义记忆（Semantic Memory）。程序性记忆（Procedural Memory）作为长期记忆理论中的一种类型保留概念边界，但当前健身 / 饮食业务不单独建设程序性记忆存储。

行为经验归别的模块管：训练智能体如何规划训练、饮食智能体如何调用工具、某类任务按照什么步骤执行，这类行为主要由 Workflow、Skill、Prompt 和 Tool Runtime 管理。用户对回答组织方式的长期偏好，例如「先给结论再解释」，则属于用户语义记忆或画像中的 `interaction_preference`，而不是单独学习一条智能体行为程序。

当前系统的长期用户认知因此形成下面这条链路：

```text
情节记忆
记录发生过什么
        ↓
语义巩固
        ↓
语义记忆
表达当前能够形成的长期认知
        ↓
画像投影
        ↓
用户画像
提供当前任务的快速读取视图
```

这三层并不是相同数据的不同副本，它们承担不同的数据语义和更新方式。三层各自的更新语义（只追加 / 版本化 / 可变）见 [[7.语义巩固与用户画像#三种更新语义]]。

## 情节记忆：记录发生过什么

情节记忆保存用户长期经历中的具体事件。它描述的是「在某个时间和上下文中发生过什么」，因此必须保留时间和原始来源。

例如用户先后表达：

```text
3 月：
我最近习惯早上训练。

7 月：
换工作以后，我现在基本只能晚上训练。

8 月：
最近还是晚上训练比较稳定。
```

系统不会把这些内容维护成一个不断被覆盖的 `training_preference` 记录，而是分别保存成多个情节。旧事件即使已经不代表当前状态，依然有历史价值。

情节记忆采用只追加写入语义。新的用户状态不会修改过去已经发生的事件。只有记忆抽取本身错误、用户要求删除数据或隐私治理要求删除时，情节才会进入 `invalid` 或 `deleted` 状态。

## 语义记忆：形成长期认知

语义记忆是在一个或多个情节基础上形成的用户长期认知。它描述的不是单次事件，而是系统根据已有证据当前可以支持的判断。

例如给定这些情节：

```text
E1：用户过去偏好晨练。
E2：工作时间发生变化。
E3：用户明确表示目前主要晚上训练。
E4：近期训练记录也主要发生在晚间。
```

可以形成：

```text
用户当前主要在晚间训练。
```

语义记忆必须能够追溯自己的证据，因此会保存与相关情节的 `derived_from` 关系。它不是简单把多个情节合并成一句话后删除原数据，而是在历史层之上新增一层更适合长期读取的抽象表示。

语义记忆同样不直接覆盖旧认知。当一个用户状态发生长期变化时，新语义作为新版本写入，旧语义保留为历史版本。例如：

```text
S1:
training.preference.time = morning
valid_to = 2026-07
status = historical

S2:
training.preference.time = evening
valid_from = 2026-07
status = current
```

这样系统既能快速判断当前状态，也不会失去用户状态变化的历史轨迹。这个状态版本化过程由 [[7.语义巩固与用户画像#语义巩固]] 完成，而不是由记忆抽取直接写入。

## 边界问答

**1. Q：** 为什么不单独建设程序性记忆？

**A：** 当前健身 / 饮食业务的行为经验（如何规划训练、如何调用工具、按什么步骤执行）主要由 Workflow、Skill、Prompt 和 Tool Runtime 管理，不需要作为一条智能体行为程序单独学习。用户对回答组织方式的偏好属于语义记忆或画像的 `interaction_preference`，是用户语义，不是智能体行为程序。

**2. Q：** 为什么训练时间偏好不维护成一条不断被覆盖的记录？

**A：** 用户对训练时间的偏好会随现实变化。若覆盖，过去偏好晨练的事实就丢失了；只追加的情节保留每个时间点的经历，语义记忆在历史层之上新增当前认知版本，画像给出当前值。三者共同支持「用户现在到底喜欢什么时候练、这个变化何时发生、为什么发生」这类问题。

**3. Q：** 为什么语义记忆是「新增版本」而不是「覆盖旧值」？

**A：** 状态发生变化时，旧语义曾经是正确认知，需要保留供追溯和冲突分析；新语义表达当前应采用的新认知，二者通过 `valid_from` / `valid_to` 和 `status` 区分当前与历史。

**4. Q：** 语义记忆和情节记忆是同一份数据的两个副本吗？

**A：** 不是。情节是历史层，只追加；语义记忆是在历史层之上形成的抽象认知，版本化。二者更新语义、读取用途不同，不能互相替代。
