# 个人健康管理agent · 项目总览

## 项目定位

个人健康管理 agent 是用户正在设计开发的健身/饮食健康管理系统。业务域分为健身与饮食两个领域：由会话主管（Supervisor）统一协调训练智能体与饮食智能体两个领域智能体，习惯作为会话主管的轻量能力，每日计划是训练智能体的领域工作流。设计文档按「章节（角度）」组织，每个章节下以「概念笔记 + 流程笔记 + 索引」的方式编排。
