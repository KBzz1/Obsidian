# 第一章 总览：跨请求的任务生命周期

## 章节定位

第一章回答一个问题：一个 Agent Task 现在究竟执行到哪里。

Harness 控制平面负责智能体任务如何被创建、推进、中断、恢复和结束。它维护的是执行状态，而不是业务事实。本章回答的四个问题都是这一主问题的展开：

- 系统现在执行到哪一步
- 下一步应该执行什么
- 任务中断以后从哪里继续
- 哪些状态属于智能体运行时，哪些数据属于正式业务事实
