# LangGraph 总览

建这个目录的原因：LangGraph 的框架知识此前散在项目笔记里，检查点、interrupt、supervisor 各被某一章按需引用，缺一处按框架自身体系完整讲清的地方。这里照官方文档的结构客观搬运整理，与项目解耦；项目只当实践例子。

每个板块一个编号子目录，总览留在本目录根上；笔记文件名保留「板块号.序号」前缀（如 `2.1`）。下方清单跟踪搬运进度，笔记粒度与清单不一致时，以实际笔记为准回来更新。2026-09-07 首轮搬运完成：20 篇新笔记加 2.1，内容以 docs.langchain.com 实际抓取为准（1.3、1.4 并入 2.1）。

## 搬运工作流

1. 来源是 LangGraph 官方文档（docs.langchain.com 的 LangGraph 部分）。
2. 给 URL 或贴原文，提取后归入对应板块，整理成概念笔记：frontmatter（tags、类型: 概念笔记、状态）→ 概念讲解 →「实践例子」callout → 边界问答。
3. 概念讲解只写框架本身；项目对照只进 callout，一到两句加链接。
4. 笔记落盘后回本文勾选清单；粒度有变同步改清单。
