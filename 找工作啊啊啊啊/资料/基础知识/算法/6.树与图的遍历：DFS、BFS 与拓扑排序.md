# 树与图的遍历：DFS、BFS 与拓扑排序

## 树的遍历

二叉树四种遍历按访问根的时机分：前序（根左右）、中序（左根右）、后序（左右根）——递归写法天然如此，迭代版用显式栈模拟递归；层序按层从上到下，用队列（即 BFS）。一个绑定知识点：中序遍历二叉搜索树（BST）得到升序序列——BST 左小右大的定义落在中序上就是有序，验证 BST、求 BST 第 k 小都走这条路。遍历的复杂度 O(n)，每个节点访问一次。

## 图的存储与两种遍历

图的两种主流存法：邻接表——每个点挂一个邻居列表，空间 O(V + E)，扫邻居方便，是默认选择；邻接矩阵——V×V 的矩阵记两点是否相邻，判断任意两点相邻 O(1)，但空间 O(V²)，稀疏图大量格子空置。遍历两种，都靠 visited 集合防止环上打转：

DFS（深度优先）沿一条路走到底、无路可走再回头换分支，递归或显式栈实现；BFS（广度优先）从起点一层层向外扩，队列实现：

```python
from collections import deque

def bfs(graph, start):             # graph：邻接表 {点: [邻居...]}
    visited = {start}              # 入队即标记，防重复入队
    q = deque([start])             # 双端队列当 FIFO 队列用
    while q:
        v = q.popleft()            # 取队首
        for w in graph[v]:         # 扫邻居
            if w not in visited:
                visited.add(w)     # 标记后入队
                q.append(w)
```

注意「入队即标记」而不是「出队才标记」：后者会让同一节点在队列里排两份，重复处理。

BFS 的关键性质：无权图上第一次到达某点所走的边数就是最短距离——所有长度为 k 的路径同步推进，先到的必然不绕远。带权图上这个性质失效（先到的不一定总代价最小），要 Dijkstra：优先队列每次取当前距离最小的点、松弛它的邻居，非负权才保证正确。选型口径：无权最短路 BFS，非负带权 Dijkstra，DAG 任意权（含负权）按拓扑序松弛一遍即可——处理某点时它的所有前驱已定型。

DFS 与 BFS 的选型：DFS 适合「一条路走到黑」的问题——连通性、判环、路径存在、回溯类枚举，栈空间 O(深度)；BFS 适合「最少步数、最浅、按层」的问题——最短路、层序、扩散模拟，队列空间 O(最宽一层)。解树很宽时 BFS 吃内存，很深时 DFS 的递归栈是风险点。

## 拓扑排序：DAG 的依赖序

拓扑排序把有向无环图（DAG）的点排成线性序列，使每条边 u→v 都满足 u 排在 v 前。应用全是依赖排序场景：课程先修关系、构建系统的模块依赖、任务编排的执行顺序。主流写法是 Kahn 算法：统计每个点的入度，入度为 0（无前置依赖）的点入队；出队时输出，并把它的每个邻居入度减一，减到 0 再入队；队列跑空后若输出数少于总点数，说明剩下的点互相依赖成环——拓扑排序顺带成为判环与检测「依赖死锁」的工具（课程表系列问题就是这个模型）。

## 束搜索：BFS 的工程变体

BFS 无差别扩展队列里的所有候选，候选量指数增长时撑不住。把「保留全部候选」收紧成「只保留最有希望的 k 个」（按启发式分数），BFS 就变成束搜索（beam search），k 称为束宽——用完备性换规模。两个工程实例：HNSW 底层搜索就是束宽为 ef 的束搜索（[[2.ANN 检索：HNSW 与召回率权衡]]）；LLM 解码里的同名束搜索每步只保留累计概率最高的 k 条候选序列。ef 或 k 越大越接近穷举、越准也越慢，这组旋钮在两边是同一件事。

> [!example] 实践例子
> LangGraph 的 StateGraph 本身是 DAG：节点按边依赖推进，与拓扑排序同一套依赖逻辑（图与执行模型见 LangGraph 目录）。检索侧 HNSW 的束搜索是 BFS 的带启发式版本（[[2.ANN 检索：HNSW 与召回率权衡]]），束宽 ef 就是那条「召回换延迟」的主旋钮。

## 边界问答

**1. Q：** 为什么 BFS 只在无权图上给最短路？
**A：** BFS 按层数推进，隐含假设「每条边代价相同」，第 k 层到达即走了 k 步。带权图上先到达的路径总代价未必最小，改用 Dijkstra（贪心 + 优先队列，非负权）或 DAG 按拓扑序松弛（可含负权）。

**2. Q：** DFS 递归写在工程里要注意什么？
**A：** 栈深。Python 默认递归深度约 1000，深图或退化成链的树会 RecursionError；改显式栈的迭代版是正解，sys.setrecursionlimit 放宽只是权宜——每层栈帧占真实内存，放太深会段错误。

**3. Q：** 拓扑排序的结果唯一吗？
**A：** 不唯一：同一时刻队列里可能有多个入度 0 的点，取哪个都对。只有每步恰好一个可选（存在全序）时结果才唯一。判环除了「输出数不足点数」，也可以用 DFS 三色标记——遇到「正在访问中」的点又走回来（回边），即有环。

**4. Q：** 邻接表还是邻接矩阵？
**A：** 默认邻接表：空间 O(V + E) 与真实边数成正比，扫邻居是遍历链表。只在「图很稠密」且「频繁查询任意两点是否相邻」时用矩阵——判断 O(1) 的便利才抵得过 O(V²) 的空间。面试图的题绝大多数用邻接表写。
