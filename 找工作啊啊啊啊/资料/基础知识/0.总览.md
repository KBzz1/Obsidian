> 本目录是语言、网络与后端基础知识的唯一归属地，按主题分六个子目录：Python 语言知识收在「Python」，网络基础收在「网络层」，操作系统、数据库、向量检索、认证与授权各成子目录，编号各自独立从 1 起。健康管理项目不进入知识正文，只以各笔记末尾「实践例子」callout 出现。

# 基础知识总览

建这个目录的原因：项目章节与 LLM API、MCP 的笔记踩在几组基础概念上——第一章并发控制依赖 asyncio，LLM API 与 MCP 的请求形态踩在网络协议上；目标岗位是 AI Agent 应用工程，后端面试又绕不开数据库、操作系统与认证这些通用知识。这些属于项目之外的基础知识，按 LangGraph 目录同样的原则独立成区：基础知识与项目解耦，项目只当实践例子。

## Python

收进这个子目录的原因：项目第一章的并发控制讨论（[[7.版本控制与并发]]）依赖一组 asyncio 基础概念——事件循环、协程、await、异步锁，加上解释器层的 GIL，这些属于语言层知识。Worker 进程模型属于项目的部署设计，留在第一章；这里收语言侧三篇。

- [x] [[1.事件循环、协程与 await]]：进程与线程、I/O 等待与两条并发路线、事件循环调度、await 语义、并发与并行
- [x] [[2.asyncio.Lock 与协程间互斥]]：await 间插队竞态、async with 用法、挂起与阻塞的区别、进程内锁的边界
- [x] [[3.GIL：多线程的边界与绕行]]：GIL 与引用计数、CPU 密集与 IO 密集的不同影响、多进程与 free-threading 绕行

## 网络层

- [x] [[1.网络分层模型：从数据链路层到应用层]]：TCP/IP 四层与 OSI 七层、一次 HTTPS 请求的封装路径、LLM API 知识的落层

- [x] [[3.HTTP：请求响应、方法、头部与状态码]]：URL 与 endpoint、方法与幂等、鉴权头、状态码五族与重试分界、无状态、版本演进
- [x] [[4.HTTPS 与 TLS：加密握手与证书]]：明文三风险、对称与非对称分工、TLS 1.3 握手、证书与 CA、前向保密
- [x] [[5.SSE：HTTP 上的服务端单向推送]]：事件格式与字段、自动重连、无 Content-Length 的交付与代理缓冲
- [x] [[6.WebSocket：HTTP 升级出的全双工通道]]：升级握手、帧与保活、与 SSE/HTTP 对比与选型

## 操作系统
